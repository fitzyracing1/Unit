# Concept: one pentacene molecule as receiver and clock

A receiver can shrink to one molecule if that molecule is both the field transducer and the frequency reference. Pentacene in p-terphenyl already does both at room temperature.

ZFS clock lines: ~108 MHz, 1.340 GHz, 1.448 GHz.
Receive chain: optical pump → T1 → ZFS clock → incoming field → fluorescence contrast.
Bench: P0 ensemble ODMR, P1 echo, P2 Ramsey mixer, P3 single molecule.
